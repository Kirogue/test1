# Acolyte Fight

This is a small prototype for an improved version of **Acolyte Fight.io** built with Node.js, Express and Socket.IO. The client renders a basic canvas and supports keyboard movement synced with the server.

## Setup

```bash
npm install
npm start
```

Run tests with:

```bash
npm test
```

Open [http://localhost:3000](http://localhost:3000) in your browser to play.
